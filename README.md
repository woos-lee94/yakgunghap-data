# 약궁합 데이터

iPhone 앱 **약궁합**이 받아 쓰는 약 정보 DB와 앱 안내 페이지를 두는 공개 저장소입니다.

- 앱 안내·문의: https://woos-lee94.github.io/yakgunghap-data/
- 개인정보 처리방침: https://woos-lee94.github.io/yakgunghap-data/privacy.html
- 약 정보 DB: [Releases](https://github.com/woos-lee94/yakgunghap-data/releases) — `drugdb.db`(SQLite)와 `drugdb.json`(판·크기·SHA-256·MD5)

## 약 정보 DB

공공데이터포털(식품의약품안전처 DUR 성분·품목정보, 의약품 제품 허가정보, e약은요, 건강보험심사평가원 약가마스터)과 식품안전나라(건강기능식품 품목제조 신고사항, 바코드연계제품정보)의 공공데이터를 매주 받아 가공한 것입니다. 판마다 데이터셋별 출처·이용조건(공공누리 제1유형 출처표시, 이용허락범위 제한 없음)·수집일을 릴리스 설명에 적습니다.

앱은 최신 릴리스의 `drugdb.json`을 보고, 이용자가 누를 때만 `drugdb.db`를 받아 크기·MD5·스키마·판을 확인한 뒤 바꿉니다. 확인에 실패하면 쓰던 DB를 그대로 둡니다. 이 요청에는 이용자 정보가 들어가지 않습니다.

참고 정보이며 의사·약사의 판단을 대신하지 않습니다. 경고가 없다는 것은 공공 DUR 데이터 범위 안에서 확인되지 않았다는 뜻일 뿐입니다. 가공 과정에서 생긴 오류가 있을 수 있으며, 원본은 각 출처에서 확인하세요.

이 저장소의 파일은 앱 저장소의 자동화(GitHub Actions)가 올립니다. 직접 고치지 마세요.
